# 방(Room) 시스템

스토리 장면(프롤로그)은 이어지는 스크롤 맵 대신 **배경 그림 한 장 = 방 하나**. 전투 스테이지(1-1 ~ 6-3)는 예전 3겹 패럴랙스 그대로.

- 코드: `js/rooms.js` (Rooms = 설정 → 월드 배치, RoomRuntime = 배경 · 카메라 · 출구 · 이동)
- 설정: `data/rooms/<id>.json`, 목록 `data/rooms/index.json`
- 새 배경 대응표: `docs/rooms-mapping.md` (`python3 tools/process_rooms.py`)

## 설정 파일

| 키 | 뜻 |
|---|---|
| `background` · `flip` · `tint` | 배경 그림 (뒤집기 · 색) |
| `scale` | 배율 = 115 ÷ `door.height` (그림 속 문 높이가 아카네 키 82 의 1.4배) |
| `door` | 기준으로 잰 문 (그림 px 높이, 어디를 쟀는지) |
| `floor` | 바닥선: 그림 위에서부터 실제 바닥이 시작되는 높이 (그림 px). 게임 바닥 판정(y 620)이 이 선에 온다 |
| `entry` | 입구 자리 (왼쪽 · 오른쪽, 그림 px) |
| `exits` | 출구 `{ side, x, to, after, until }`: after 장면을 봤고 until 장면은 아직이면 빛기둥이 켜지고, 닿으면 to 방으로 |
| `scenes` · `then` | 걸어 들어오면 재생할 장면 (안 본 것만) · 끝나면 (`nextChapter`) |
| `light` · `ambience` · `props` | 색감 · 환경음 · 배경 앞 소품 |
| `points` | 지점 이름 → 그림 px (예: `sapling` = 마당의 빈 흙자리) |
| `legacy` | 예전 한 줄 맵 x → 그림 px 대응 (대본 · 연출 표의 숫자를 방 안 자리로) |
| `tree` | 큰 벚나무 (축제 · 불타는 광장 · 잿더미 광장) |

## 카메라 · 이동

- 카메라는 지금 방 밖을 보여 주지 않는다 (경계 = 방 그림, 아래는 바닥선 밑 15% 까지). 방이 화면보다 작으면 기본 줌을 올려 화면을 채운다 (아카네 : 문 비율은 그대로)
- 걸어서 출구 빛에 닿으면: 잠금 → 0.25초 검게 → 0.15초 → 다음 방 입구에서 걸어 들어오며 0.25초 밝게 → 복귀
- 장면이 다른 방에서 시작하면 (`room` 명령, 장면 준비 맨 앞) 0.6초 검은 화면으로 옮기고 `roomIn` 에서 밝힌다
- 그림은 모두 장 시작 때 불러 둔다 (manifest) — 방을 바꿀 때 끊기지 않음
- 체크포인트 벚꽃나무는 숨기고, 죽으면 그 방 입구에서 부활

## 조절

F1 → 연출 시험 → 「방」 슬라이더(방마다 배율 · 바닥선) → 「방 설정 적용 (다시 시작)」(이 브라우저에 저장) · 「지금 방 파일 내려받기」(data/rooms/<id>.json 을 바꾸면 반영)
