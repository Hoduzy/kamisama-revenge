# 2D 횡스크롤 액션 (Phaser 3)

빌드 도구 없이 `index.html` + `js/` 파일만으로 동작합니다. Phaser 3.80.1은 `js/lib/phaser.min.js`에 포함되어 있어 외부 CDN이 필요 없습니다.

## 실행

- 로컬: 폴더에서 `python3 -m http.server` 후 http://localhost:8000 접속 (`index.html`을 파일로 직접 열면 `data/story/*.json`을 못 읽어 대화 없이 시작됨)
- GitHub Pages: 저장소 Settings → Pages → Source를 `Deploy from a branch`, 브랜치/루트(`/`) 선택

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | A / D (←/→) | ◀ ▶ |
| 점프 | Space (W/↑) | 점프 |
| 공격 | J | 공격 |
| 대시 | K (Shift) | 대시 |
| 스킬1 대쉬베기 | U | 베기 |
| 스킬2 발도 | I | 발도 |
| 일시정지 | ESC | 오른쪽 위 둥근 버튼 |
| 재시작 | R | 일시정지 메뉴 · 클리어 후 화면 탭 |

- **일시정지 메뉴** (ESC 또는 화면 오른쪽 위 버튼):
  - 이어 하기 · 처음부터 다시 · 조작 방식(키보드/터치) · 조작 안내 · 연출 시험 · 개발 메뉴. F1이 안 눌리는 기기에서도 열 수 있다.
  - 게임 화면, 컷신 대기(자막·자동 넘김), 글자 레이어 애니메이션, 음악이 모두 멈춘다.
  - 컷신 중 ESC는 장면 건너뛰기다.
- **조작 방식**: 일시정지 메뉴에서 바꾼다(화면 버튼이 나타나거나 사라짐). 브라우저가 기억한다. 주소에 `?input=touch` / `?input=keyboard`를 붙여도 된다. 고르지 않았으면 터치 화면이 있는 기기는 터치, 아니면 키보드.
- **1-1 조작 안내**: 1장 첫 스테이지에서만, 그 행동이 필요한 자리(이동·공격·점프·대시·대쉬베기·발도)에 작게 뜬다. 한 번 해 보면 다시 나오지 않는다(브라우저가 기억, `js/level.js`의 `hints`).

- 점프: 코요테 타임 0.1초, 점프 버퍼 0.12초, 키를 일찍 떼면 낮게 뜀(가변 점프), 정점 체공, 하강 시 중력 증가
- 대시: 지상/공중 1회, 대시 중 몸통 무적, 지상 대시는 점프로 캔슬
- 공격: 공중에서 적을 맞히면 살짝 떠오름, 적을 위에서 밟으면 튕겨 오름

## 스킬

- **대쉬베기 (U)**: 바라보는 방향으로 짧게 대쉬하며 지나가는 적을 벤다. 대쉬 중 무적. 적을 맞힐 때마다 벚꽃 스택 +1 (최대 5).
- **발도 (I)**: 1초 준비 후 앞으로 강하게 벤다.
  - 준비 0~0.5초: 패링. 부딪힌 적이 대신 피해를 받는다 (분홍 테두리 표시).
  - 준비 0.5~1초: 맞으면 스킬이 끊기고 쿨타임 시작. 체력은 1 밑으로 내려가지 않는다.
  - 피해 = 기본 피해 + 벚꽃 스택 × 스택당 피해. 스택을 모두 소모하고 꽃잎이 터진다.
- 화면 하단에 스킬 쿨타임과 벚꽃 스택 5칸이 표시된다.
- 쿨타임·피해량·대쉬 거리 등 수치는 `js/config.js`의 `dashSlash`, `iaido`, `sakuraMax`에서, 적 수치는 `swordsman`, `thrower`, `shuriken`에서 수정.

## 규칙

- 체력은 1칸. 적의 검이나 수리검에 맞으면 즉시 죽고, 마지막으로 만개시킨 **벚꽃나무**에서 바로 부활한다.
- 벚꽃나무에 가까이 가면 꽃잎이 터지며 만개하고 부활 지점이 된다.
- 적과 몸이 부딪히는 것만으로는 죽지 않는다. 위에서 밟으면 피해를 준다.
- 대시(K)와 대쉬베기(U) 중에는 공격을 맞지 않는다.

## 적

- **근접 검사**: 쫓아와서 0.4초 동안 빨간 예고 영역과 `!`를 띄운 뒤 벤다. 예고 중에 때리면 공격이 끊긴다.
- **원거리 투척병**: 플레이어를 향해 수리검을 던진다. 가까이 가면 뒤로 물러난다.
  - 수리검은 기본 공격(J)으로 쳐낼 수 있고, 발도 패링 구간에 맞으면 던진 적에게 되돌아간다.
- **교주 아마테루 (보스, 임시)**: 근접 검사 AI를 크게 키우고 수리검 3개를 부채꼴로 던진다. 맞아도 공격이 끊기지 않는다. 수치는 `config.js`의 `boss`.

## 스토리

에도 막부 시대. 적안 흑발 고양이귀 소녀 **아카네**가 부모를 잃고, 그 원인인 사이비 사무라이 집단 **카미사마**에게 복수하러 간다.

### 대본 데이터 (`data/story/`)

- 대본 원고(`docs/*.md`)를 `python3 tools/convert_story.py`로 변환한 JSON. 장마다 한 파일: `prologue`, `ch1`~`ch6`, `epilogue`, `memories`, 인물은 `characters.json`. 변환 결과 요약은 `_report.md`.
- 장면 = `{ id, place, trigger, controllable, commands }`. 명령: `say`(대사) `think`(속마음) `voice`(목소리) `caption`(붓 자막) `fadeOut/fadeIn` `letterbox` `shake` `flash` `slowmo` `bgm` `sfx` `cg` `titleCard` `bossName` `giveItem` `wait` `cameraPan` `condition` `choice` `setFlag` `include` `note`(연출 메모).
- 풀(pools): 체크포인트 한마디. 타누키치는 50%(스테이지 첫 체크포인트는 확정), 장 안에서 다 쓸 때까지 반복 없음, 하루 목소리가 나오면 생략, 3초 말풍선. 하루 목소리는 10%(6장은 확정).

### 컷신 엔진 StoryPlayer (`js/story-player.js`)

- **트리거 ↔ 장면 id**는 `js/level.js`의 `STORY_MAP` 표에 장별로 적는다 (장마다 쓰는 맵은 `levelFor(장)`: 프롤로그는 `LEVELS.prologue`, 나머지는 아직 `LEVELS.town`):
  - `start` 장 시작 때, `triggers` 주인공이 x를 넘을 때(`stage`, `then: 'wakeBoss' | 'clear'`)
  - `trees` n번째 벚꽃나무가 필 때(장면이 없으면 타누키치 한마디)
  - `boss.hp` 보스 체력 비율, `boss.after` 보스 처치 후
  - `events` 아직 게임에 없는 사건용 (`scene.storyEvent('이름')`)
  - 엔딩은 6장 선택(`choice:S6-10`)에 따라 갈린다.
- **조작:**
  - 보통 장면·레터박스 장면은 조작 잠금(게임 멈춤).
  - 조작 가능 컷신(`controllable`)은 걸으면서 대사가 자동으로 흘러간다.
  - 넘기기: Space·J·Enter·화면 탭.
  - **길게 누르면(0.8초) 장면 전체 건너뛰기** (화면 위에 게이지). Esc도 건너뛰기. 선택지는 꼭 골라야 한다.
- **CG:**
  - 장(章)을 시작할 때 로딩 화면에서 그 장의 CG·컷신 그림을 모두 미리 불러온다(`js/cg-cache.js`). 컷신 도중에는 불러오지 않는다.
  - `cg` 명령: `{no}` → `assets/cg/cg_0N.png`, `{image}` → `assets/sprites/<이름>.png`(배경 전경 등). 검은 바탕에서 0.8초 페이드인하고, 떠 있는 동안 아주 느리게 확대(`motion: 'zoom'`, 1.0→1.05)하거나 옆으로 흐른다(`'pan'`).
  - 다음 대사는 CG 위에 나온다. `cgEnd`·암전·명전·카메라 이동·장면 끝에서 0.8초 페이드아웃된 뒤 다음으로 넘어간다.
  - 자리표시("CG 번호 + 설명")는 파일이 정말 없을 때만 나온다.
- **초상화:** 도트 초상화(`sprite`)나 그림(`image`)이 없는 인물은 실루엣 + 이름 첫 글자 (`js/portraits.js`).
- **소리:** `data/story/audio.json`에 대본의 BGM·효과음 이름 → 파일 경로를 적는다. 비어 있거나 파일이 없으면 조용히 넘어간다. 변환기를 다시 돌려도 적어 둔 경로는 남는다.
- **연출 메모(note):** 아직 게임으로 옮기지 못한 연출은 개발 모드에서만 왼쪽 위 구석에 작게 보인다.
- **저장:** 플래그·선택·재생 기록·아이템은 registry(`storyFlags`, `storyPlayed`, `items`)에 있다.
- **설정:** 글자 속도는 `config.js`의 `dialogue`, 자동 넘김·길게 누르기·음량은 `story`.

### 게임플레이 연결 (`js/gameplay.js`)

- 대본의 연출 메모 중 게임 동작은 변환기(`tools/convert_story.py`의 `GAMEPLAY` 표)가 `{cmd:'gameplay', do: …}` 명령으로 바꾼다. 대본을 다시 변환해도 유지된다.
- 튜토리얼·전투처럼 조작이 필요한 동작은 잠긴 장면에서도 그동안만 조작이 풀리고, 건너뛰기를 해도 꼭 해야 한다. 보여 주기만 하는 동작은 건너뛰면 결과로 바로 간다.
- 맵 데이터에 더 들어가는 것:
  - `npcs`(이야기 속 인물: 하루는 주인공 그림을 분홍빛으로, 나머지는 실루엣 + 이름표)
  - `points`(인물이 갈 위치)
  - `gates`(그 장면을 끝까지 보기 전엔 못 지나가는 보이지 않는 벽)
  - `enemies[].group`(gameplay `spawn`·`fight`로 나타나는 무리)
  - `decorTrees`(체크포인트가 아닌 장식 나무)
  - `memories`(기억 조각 위치)
  - `mood`(화면 분위기 dusk / night / fire)

### 프롤로그 (`?chapter=prologue`)

연습장 → 대장간 → 축제 광장 → 불타는 골목 → 대장간 앞 → 불타는 광장 → 1장으로 이어진다.

- **S0-2 연습장** (걸으며 진행): 이동 → 낮은 담 점프 → 허수아비 3개 대쉬베기(이때 대쉬베기·벚꽃 스택 칸이 처음 나타남) → 발도 → 하루와 패링 연습(맞아도 안 죽음, 성공할 때까지. 성공하면 하얀 섬광 + 슬로모션). 대쉬베기·발도는 배우기 전엔 못 쓴다.
- **S0-3 대장간**: 칼 획득.
- **S0-4 축제 광장**: 하루가 큰 벚나무를 피움 → 마을 사람들 환호 → 하루에게 다가가면 귓속말 → 종소리 → 불화살, 화면이 붉게 바뀌고 불티가 날린다.
- **S0-5 불타는 골목** (벚꽃나무 1): 가면 신도 2명과 첫 실전.
- **S0-6 대장간 앞** (벚꽃나무 2): 신도 3명. 마지막 한 명을 벨 때 슬로모션 → 소이치로가 무릎 꿇고 지붕이 무너진다.
- **S0-7 불타는 광장**: 대화 → 하쿠야 패배 이벤트 전투(공격은 금빛 막에 튕기고 체력바가 줄지 않음. 20초가 지나거나 3번 맞으면 끝, 맞아도 안 죽음) → 하쿠야의 발도에 아카네가 날아가 쓰러짐 → 하루가 막아서다 쓰러짐 → 꽃잎 소용돌이 → 꽃잎에 실려 사라짐.
- **S0-8**: 검은 화면 자막 → 타이틀 → 1장 시작.
- R을 누르면 프롤로그는 처음부터 다시 시작한다(연출이 이어져 있어서). 죽으면 마지막 벚꽃나무에서 부활한다.
- 기억 조각: 대본 표(`memories.json`)에 따르면 1-1 ~ 6-3에만 있어 프롤로그에는 없다. 1장 3개(1-1 지붕 끝, 1-2 쌀가게 지붕, 1-3 다리 아래)는 지금 마을 맵에 놓았다. 먹으면 `기억 조각 N · 제목`이 뜨고 registry `memories`에 저장된다.

### 연출 도구 (`js/cinematics.js`, 명령 표: `docs/cinematics.md`)

모든 장에서 쓰는 카메라·시간·화면 효과·빛과 입자·길 안내·소리 도구. 대본의 연출 명령으로 쓰고, F1 → `🎬 연출 시험`에서 하나씩 시험한다.

- **카메라**:
  - 룩어헤드: 움직이는 쪽으로 화면 폭 15% 앞을 비추고 부드럽게 따라간다. 게임 전체에 늘 켜져 있다.
  - 줌, 패닝 후 복귀, 틸트
  - 흔들림 약·중·강 + 세로 충격
  - 레터박스 0.4초
- **시간**: 히트스톱(완전 정지), 슬로모션(끝날 때 부드럽게 복귀)
- **화면**:
  - 플래시(흰·붉은·금), 비네트
  - 색감 전환(해 질 녘 → 밤 → 불, 2초)
  - 흑백 1프레임 컷, 탈색. 캔버스 CSS 필터라 도트가 유지된다.
  - 산나비식 컷인(가로 띠 안에 초상화의 눈)
- **빛과 입자**:
  - Light2D 점광원(등롱·화로·횃불·불길, 깜빡임, 주변광 낮추기)
  - 입자 8종(벚꽃잎·불티·연기·재·짚·불꽃·김·먼지)
  - 전경 실루엣(등롱 줄·벚꽃 가지·불타는 기둥, 1.3배 패럴랙스)
- **길 안내**:
  - 멈춰 있으면 화면 끝에 붓 화살표
  - 목적지 쪽 꽃잎·불티 바람
  - 목표 자막 〈…〉
  - 머리 위 행동 키(하면 먹물처럼 번짐, 터치 버튼도 빛남)
  - 빛나는 출구
- **소리**:
  - 효과음: `sfx(id)`. `assets/sfx/<id>.ogg|mp3|wav`가 있으면 그 파일, 없으면 ZzFX(`js/lib/zzfx.js`, MIT) 임시 소리.
  - 음악: `bgm(id, 페이드)`, 대사 중 자동 볼륨 낮춤, `silence`.
- **수치**: `config.js`의 `TUNING.cine`. 연출 시험의 슬라이더로 바꾸고 브라우저에 저장하거나 `config.js`로 저장한다.

### 개발 메뉴 (F1)

- 장 이름 옆 `▶ 처음부터 이어서`: 그 장을 처음부터 실제 게임처럼 이어서 플레이한다.
- 아무 장면 id나 바로 재생한다. 검색은 id·장소·대사로 하고, ↑↓·Enter 또는 클릭으로 고른다. 장면이 속한 장으로 다시 시작한다.
- 개발 모드 켜고 끄기 (연출 메모·소리 이름 표시). 주소에 `?dev=1`을 붙여도 켜지고, 브라우저가 기억한다.
- 기억 조각 개수 설정, 본 장면·플래그 지우기.

### 테스트용 주소

- `index.html?scene=TEST` — 모든 연출 명령 시연 (`data/story/test.json`)
- `index.html?scene=S0-7` — 장면 하나만 재생
- `index.html?chapter=prologue` — 프롤로그부터 (기본 ch1, `ch3`·`epilogue` 등도 가능)
- `index.html?scene=E-5&memories=18` — 기억 조각 개수 조건 시험

## 그림 (스프라이트)

- 원본: `assets/raw/` → `python3 tools/process_sprites.py` → `assets/sprites/` (시트 PNG + `manifest.json` + `preview.html`)
- 게임은 시작할 때 `manifest.json`을 읽어 시트·배경·타일을 불러온다 (`js/sprites.js`, `js/boot-scene.js`). 그림을 못 읽으면 예전 도형으로 그린다.
- 판정은 그림과 별개인 몸통 사각형 (주인공 28×60). H 키로 판정 표시 (기본은 꺼짐).
- 배경: bg_far(밤하늘·달, 0.05배 스크롤, 3배 확대) → bg_mid(마을, 0.3) → bg_near(난간, 0.6). 앞쪽일수록 어둡게 틴트.

### 프롤로그 그림 (CG·구역 배경)

- 원본 `assets/raw/`: `cg_01`(축제 밤의 가족), `cg_02`(꽃잎에 감싸인 아카네와 손을 뻗는 하루), `bg_pro_yard`(해 질 녘 연습장), `bg_pro_forge`(대장간 안), `bg_pro_festival`(축제 광장), `bg_pro_alley`(불타는 골목), `bg_pro_burning`(불타는 광장).
- `python3 tools/process_sprites.py --only cg_01 cg_02 bg_pro_yard bg_pro_forge bg_pro_festival bg_pro_alley bg_pro_burning`
  - 도트 크기 추정이 그림마다 2.7~6으로 흔들려서 모두 도트 3px로 줄인다(`STAGE_BG_DOT`). 화면에서는 1도트 = 2px.
  - **CG**: 16:9로 위아래를 자른다(cg_02는 하쿠야 후광이 남게 위는 덜 자름). 512×288 → `assets/cg/cg_01.png`. 대본의 `cg` 명령은 `assets/cg/cg_번호(두 자리).png`를 화면 가득 띄운다.
  - **구역 배경**: 512×341 → `assets/sprites/bg_pro_*.png` + 좌우 반전 띠 `_strip.png`. 그림 아래 15%(`STAGE_BG_FLOOR`)를 바닥 띠로 보고, 그 윗선이 땅 타일 윗면에 오게 놓는다.
- 게임에서는 `LEVELS.prologue.backgrounds`에 구역(x0~x1)과 기준 위치(anchorX)를 적는다. 구역 경계 앞뒤 160px 동안 다음 배경이 겹쳐 나타난다. 패럴랙스는 0.15.
  - 연습장 0~1640
  - 대장간 1640~2330
  - 축제 광장 2330~3120
  - 불타는 골목 3120~4400
  - 불타는 광장 4400~6300 (그림 왼쪽의 불타는 대장간이 대장간 앞 S0-6 자리)
- 축제 광장과 불타는 광장은 같은 곳이라, 두 그림의 큰 벚나무 줄기(그림 가로 62%)를 각 광장의 나무 자리(2760, 5680)에 똑같이 맞췄다. 배율·패럴랙스도 같다. 광장 나무는 배경 속 나무를 쓰고, 꽃 피는 효과만 그 자리에 낸다.

### 프롤로그 인물·마을 사람·소품 (`python3 tools/process_prologue.py`)

- **크기**: 머리 높이를 아카네(player_idle)와 맞춘다. 하루 ×1.05, 소이치로 ×1.15, 하쿠야 ×1.2, 마을 남자·여자 ×1.0, 아이 ×0.9.
  - 머리 높이는 확대한 그림에 눈금을 대고 손으로 쟀다(`CHARACTERS`). 하루·하쿠야의 크림색 옷이 피부로 잡혀서 자동으로는 틀렸다.
  - 같은 인물의 다른 시트는 머리 띠를 본으로 크기를 맞춰 보고(OpenCV), 점수가 낮은 시트는 같은 캔버스의 서 있는 키를 견주어 손으로 정했다(`SHEET_SCALE`).
- **배경**: 투명으로 왔지만, 바깥과 이어진 큰 흰 덩어리가 남아 있으면 그것만 지운다. 이번 그림들에는 없었다.
- **boss 시트**: 하쿠야 기준 그림 정면으로 바꿨다. 판정은 `config.js`의 `boss.body` 36×76.
- **마을 남자·여자**: 옷 색만 바꾼 변형 `_v1`~`_v3`가 있다. 피부·머리는 그대로다.
  - 축제에서 춤추다가 불화살이 떨어지면 양쪽으로 도망친다.
  - 불타는 골목에서는 신도가 들이닥치면 도망친다.
- **소품·이펙트 시트**: 조각마다 나눈다(원본 좌표 상자는 손으로 정함). 금빛 막·빛은 반투명을 살린다.
- **타이틀**: 로고 문양(`logo_emblem`) 위에 둥근모꼴로 `GAME_TITLE`(config.js, 지금은 「카미사마」)을 붓글씨처럼 쓴다.
- **대본 순서**: S0-3 대장간(칼 선물)이 S0-2 연습장 앞으로 왔다. 맵도 대장간 0~700 → 연습장 700~2330 순서다.
- 확인: `assets/sprites/preview.html` (프롤로그 인물 줄 세우기, 마을 사람 색 변형 포함)

## UI (에도풍)

- 원본 `assets/raw/ui_*.png` → `python3 tools/process_ui.py` → `assets/ui/*.png` + `assets/ui/ui.json`.
  - 한 장에 여러 조각이 있으면 빈 줄·빈 칸으로 나누고, 도트 해상도로 줄인다.
  - 틀 그림의 9-slice 값(장식이 있는 모서리·끝은 늘어나지 않게)과 칸 위치는 `tools/ui_slices.json`에 적는다.
  - 게임은 `UI.nine(요소, 이름, 배율)`로 CSS border-image를 입힌다.

| 그림 | 쓰는 곳 |
| --- | --- |
| `ui_dialogue_frame` | 대화창 틀 (9-slice) |
| `ui_nameplate` | 이름표 (9-slice) |
| `ui_skill_frame_a` / `_b` | 왼쪽 아래 스킬 칸 2개 |
| `ui_scabbard` | 벚꽃 스택 칼집 게이지 (소켓 5개) |
| `ui_scroll_open` → `ui_scroll_roller_l` · `ui_scroll_paper` · `ui_scroll_roller_r`, `ui_scroll_closed` | 결과창 두루마리 |
| `ui_plaque` | 상단 카운터 명패, 일시정지 메뉴 판 (9-slice) |
| `ui_medallion` / `_pressed` | 일시정지 버튼, 터치 버튼 |

- **대화창**: 나타날 때 붓으로 칠하듯 왼쪽 → 오른쪽으로 드러난다(붓결 마스크).
- **결과 화면** (`js/result-screen.js`, 그림: `python3 tools/process_result.py` → `assets/result/`, 수치: `config.js`의 `TUNING.result`):
  1. 히트스톱 → 게임 화면이 어두워지고 탈색 → 가장자리 장식 → 레터박스
  2. 닫힌 두루마리가 떨어져 튕기고 펼쳐짐 (화면 폭 55%)
  3. 장 이름을 한 글자씩
  4. 1인칭 손이 오른쪽 위에서 들어와 칼날이 반짝
  5. 손이 가로질러 베고 칼날 궤적이 재생됨 (각도 = `slashAngle`)
  6. 히트스톱 + 흰 플래시 + 흔들림
  7. 두루마리가 궤적대로 잘려(같은 구성을 다각형 마스크로 나눔) 단면을 달고 날아감, 종이 조각·꽃잎이 흩날림
  8. 먹물이 번지고 「討伐」 그림이 왼쪽 → 오른쪽으로 붓질하듯 드러남 → 북 소리
  9. 斬 · 死 · 시간 · 기억 조각 → '점프 · 공격으로 계속'
  - 보스를 쓰러뜨렸을 때는 4~6을 좌우 반전해서 두 번 베고(X 자), 두루마리가 네 조각으로 흩어진다.
  - 게임 화면과 결과 화면을 다른 카메라로 그려서, 어둡게·탈색은 게임 화면에만 걸린다.
  - F1 → `🎬 연출 시험`: 결과 화면 슬라이더(빠르기, 두루마리 폭, 각도, 시간들, 크기)와 `결과 화면 (일반/보스)` 시험 버튼.
- **상단 카운터**: 나무 명패 위 「死 0」 「斬 0」.
- **왼쪽 아래**: 스킬 칸 2개(아래에 키 글자 U, I). 쿨타임 동안 아이콘 위의 먹물이 위에서부터 빠진다. 그 옆 칼집 게이지 소켓에 벚꽃 스택이 하나씩 피어나고, 발도로 쓰면 흩날린다.
- **폰트**: 모든 글자가 둥근모꼴(`assets/fonts/DungGeunMo.woff2`, 원본 `.ttf`) 하나다. 16px 격자 픽셀 글꼴이라 글자 크기는 16 · 32 · 48px만 쓰고, 안티앨리어싱을 끈다 (`js/pixel-font.js`).
  - 화면 배율은 기기 픽셀 기준 정수배(1920×1080 화면이면 2배)라 글자와 도트가 흐려지지 않는다. 창이 작아 정수배로는 화면의 70%도 못 채울 때(휴대폰 등)만 비정수 배율로 꽉 채운다 (`TUNING.screen`).
  - 둥근모꼴에는 한자와 ▶ ▼ 가 없다. 장 제목은 「제1장」, 프롤로그는 「서장」, 마지막은 「끝」, 상단 카운터는 「죽음 · 처치」로 쓰고, ▶ ▼ ◀ ▲ 는 4px 네모로 쌓은 픽셀 화살표로 자동으로 바뀐다. 결과 화면의 「討伐」은 그림이다.
  - `python3 tools/check_glyphs.py`: 대본·코드에 글꼴에 없는 글자가 있으면 목록으로 경고한다. 대본을 변환할 때(`tools/convert_story.py`)도 끝에 자동으로 돈다. fontTools 가 필요하다 (`pip install fonttools`).
- **배경과 어울리게**: 바닥 타일 밝기 70%(그 아래 돌담 55%, 예전 검은 띠 대신), 벚꽃나무는 캐릭터보다 뒤 레이어.

## 파일 구성

- `js/config.js` — 조작감 튜닝 값(가속, 점프, 대시 등)을 한 곳에 모음
- `js/touch.js` — 화면 버튼(멀티터치, 손가락 슬라이드 지원), 조작 방식(터치/키보드) 선택
- `js/controls.js` — 키보드 + 터치 입력 통합
- `js/skills.js` — 대쉬베기, 발도, 벚꽃 스택
- `js/tree.js` — 벚꽃나무(체크포인트)
- `data/story/` — 대본 JSON (`tools/convert_story.py`로 생성)
- `js/gameplay.js` — 대본의 gameplay 명령(튜토리얼, 전투, 인물 이동, 패배 이벤트 …)
- `js/npc.js` — 이야기 속 인물
- `js/story-player.js` — 컷신 엔진 StoryPlayer (장면 재생, 길게 눌러 건너뛰기, 소리, 풀, 플래그)
- `js/dev-menu.js` — F1 개발 메뉴, 개발 모드
- `js/pause-menu.js` — 일시정지 메뉴 (ESC)
- `js/cinematics.js` — 연출 도구 (카메라·시간·화면·빛·입자·길 안내·소리)
- `js/cine-lab.js` — F1 연출 시험 창
- `js/lib/zzfx.js` — ZzFX 임시 효과음 (MIT)
- `js/result-screen.js` — 결과 화면 (두루마리 베기 → 討伐)
- `js/dialogue.js` / `js/portraits.js` / `js/boot-scene.js` — 대화창, 초상화 그리기, 대본·스프라이트 로딩
- `js/ui.js` — HTML 글자 레이어 + 컷신 연출(페이드, 레터박스, 자막, CG, 선택지, 말풍선)
- `js/sprites.js` — 스프라이트 애니메이션·이펙트 도우미
- `tools/process_sprites.py` — 원본 도트 이미지 전처리
- `tools/process_ui.py` / `tools/ui_slices.json` — UI 그림 전처리, 9-slice 값
- `tools/process_result.py` — 결과 화면 그림 전처리
- `tools/process_prologue.py` — 프롤로그 인물·마을 사람·소품·이펙트 전처리 (scipy, opencv-python-headless 필요)
- `js/player.js` / `js/enemy.js` — 주인공, 적
- `js/level.js` — 맵(`LEVELS.town`, `LEVELS.prologue`), 스토리 트리거 ↔ 장면 id 표(`STORY_MAP`)
- `js/game-scene.js` — 충돌, 전투, 카메라, HUD
